# Обновление сезона NikoBoost

Единственный файл с сезонными данными: **`src/data/season.ts`**. Компоненты и сервер используют его через совместимые экспорты `wowSeason.ts`, `delves.ts`, `delveArt.ts` и `mythicPlus.ts`. Не дублируйте таблицы в компонентах или API.

| Что меняется | Где в season.ts |
| --- | --- |
| Название, патч, дата проверки, ссылка Blizzard | `wowSeason` |
| Сброс сохранённых планов при новом сезоне | новое уникальное `wowSeason.id` |
| Ротация Mythic+ и картинки | `dungeons`, `dungeonImages` (имя → имя JPG без расширения) |
| Награды, треки улучшений, Crests | `mythicRewards` |
| Пороги Great Vault Mythic+ | `vaultThresholds` |
| Цены Mythic+ в золоте | `mythicBasePrices` |
| Стартовые ключи, максимальный ключ Crest Farming | `mythicDefaults`, `mythicSettings`, учебный пример `mythicExample` |
| Доплаты, скидки пакетов обоих сервисов | `servicePricing` (пакеты от большего к меньшему) |
| Все Delves: id, название, зона, описание | `delveLocations` |
| Цена каждого тира и награды | `delvePrices`, `delveRewards` (одинаковые ключи) |
| Рекомендованный тир, лимит забегов, пороги World Vault | `delveSettings` |
| Иллюстрации и фотокарточки Delves | `delveArt`, `featuredDelves`, `delveSettings.heroArt/heroBackdrop` |
| Текущий Nemesis и Labyrinth | `delveSpecialists` |
| Сезонные пояснения и ссылки | `delveFaqs`, `delveSettings.challengeNote`, `delveSources` |

Картинки кладите в `public/images/dungeons` (JPG) и `public/images/delves` (WebP). Пути тоже задаются в конфигурации. Для фотокарточек используйте только соответствующие локации, а не случайные иллюстрации. Сохраняйте атрибуцию в `docs/delve-images.md`.

Обновляйте цены и награды отдельно: золотые цены — собственные тарифы NikoBoost, а не обещание конкретного предмета. Непроверенную числовую награду не придумывайте: для Delve Vault можно оставить `null`. Количество Crests пока обозначено как оценка; пользователь может ввести фактическую выдачу из игры.

При смене `wowSeason.id` старые сохранённые недели перестают загружаться. Новые ссылки на планы содержат id сезона: чужой сезон не импортируется поверх текущей недели. Старые ссылки без id остаются совместимыми.

После изменений:

```bash
npx tsc --noEmit
npm run lint
npm run build
npx playwright test
```

`tests/season-config.spec.ts` проверяет полноту цен/наград, доступность стартовых значений и наличие изображений. Тесты заказов проверяют серверную цену. При изменении самих тарифов обновите ожидаемые суммы в тестах; не меняйте проверки валидации, чтобы скрыть ошибку.

Проверьте превью на компьютере и телефоне: оба сервиса, Rewards, навигация, открытие формы, расписание, выбранная локация и конечная сумма. Автотесты подменяют доставку заказов; реальные тестовые заказы в Discord не нужны. Изменения сохраняются в рабочую ветку и PR. Merge и production — отдельный шаг.
